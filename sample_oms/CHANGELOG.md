# Changelog

All notable changes to the Sample OMS app will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.9.0] - 2026-04-20

### Added
- Admin UI configuration form (`ui/admin/form.json`).

### Changed
- Updated hint text (2026-04-21 to 2026-04-22).

## [2.8.0] - 2026-04-13

### Changed
- UI template uses `dataFilter` and `dataOrder` attributes.

## [2.7.0] - 2026-03-25

### Changed
- Test updates to reflect appcfg changes.

## [2.6.0] - 2026-02-25

### Added
- UI forms.
- Test coverage for UI forms (2026-03-18).

## [2.5.0] - 2025-06-05

### Changed
- Replaced UI template.
- Renamed dataset from `success` to `customer` (2025-06-25).

## [1.0.0] - 2024-11-12

### Added
- Initial Sample OMS app: flexible card UI template; `cancel_order`, `refund_order`, `return_line_items` actions; customer/order data pulls; authentication.
- Makefile for `appcfg validate`/`test`/`build`/`run` workflows (2025-02-21).

### Changed
- Flexible-card filename corrected for card spec compliance (2025-01-21).

> Versions 1.1.0–2.4.0 were not released. (An initial 1.1.0 was tagged 2024-10-24 and renumbered to 1.0.0 three weeks later before the 2.5.0 bump.)
