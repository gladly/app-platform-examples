# Changelog

All notable changes to the BigCommerce app will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
This app uses a `MAJOR.MINOR` version scheme (no patch component).

## [6.1] - 2026-04-20

### Added
- Admin UI configuration form (`ui/admin/form.json`).

### Changed
- Updated hint text.

## [6.0] - 2025-01-23

### Fixed
- Variable type errors in data pulls.
- Action fixes.

### Changed
- Documentation updates (2025-01-28).
- Removed `unset` calls in data pulls (2025-01-28).

## [5.0] - 2024-07-10

### Removed
- Orders data pull query.

## [4.0] - 2024-07-10

### Added
- Data pull updates for BigCommerce.

> Versions prior to 4.0 predate this app's presence in source control and are not captured here.
